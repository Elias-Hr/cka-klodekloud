# cka-klodekloud

An interactive study companion for the Certified Kubernetes Administrator (CKA) course. This website is a vibe-coded, community-made version inspired by the KodeKloud CKA course. Its purpose is to help learners review Kubernetes concepts through a structured course interface, visual diagrams, code examples, lab solutions, and quizzes.

The original course repository is [KodeKloud's Certified Kubernetes Administrator course](https://github.com/kodekloudhub/certified-kubernetes-administrator-course). This project is not an official KodeKloud website and is not affiliated with or endorsed by KodeKloud.

The website is planned for GitHub Pages at:
https://elias-hr.github.io/cka-klodekloud/

To deploy, set the repository's GitHub Pages source to **GitHub Actions** under **Settings → Pages → Build and deployment**. No personal access token is needed; the workflow uses its automatically provided `GITHUB_TOKEN`.

After setup, updates pushed to `master` deploy automatically.
